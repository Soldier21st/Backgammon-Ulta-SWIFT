# Monetization Model

## Principles

- No pay-to-win mechanics.
- Monetize expression, convenience, and analytics depth.
- Preserve competitive integrity across all players.

## Free Tier

- Full gameplay access.
- Ads in non-gameplay surfaces only (lobby, post-match, menus).
- Standard stats and profile visibility.

## Premium Subscription

- Ad-free experience.
- Voice chat enabled.
- Advanced statistics and match insights.
- Exclusive cosmetics catalog segment.

## Cosmetic Marketplace

- Boards, checker sets, dice skins, profile frames.
- Seasonal collections and limited drops.
- Entitlement enforcement from server inventory records.

## Revenue Mix

- Subscription for recurring revenue.
- Cosmetics for event-driven boosts (season launches, collaborations).
- Optional battle-pass style seasonal progression can be added without affecting gameplay power.
